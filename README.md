## Overview

ProPersona is a mobile-first professional identity and career-development platform. It gives graduates and working professionals a secure, guided starting point for building a purposeful professional presence.

Phase 1 establishes the product's account, consent, profile and onboarding foundation: users can securely create or access an account, review legal consent, select a career path, and enter a protected app experience with a persisted session.

## Architecture

ProPersona follows a clear separation of responsibility:

```text
View → Controller → Repository → Firebase
                         │
                         └→ Session service → Session state → Routing
```

The app is organized by feature. Views stay focused on presentation and interaction; controllers coordinate state and use cases; repository contracts isolate data access; Firebase integrations provide the remote implementation. Bindings compose dependencies, while middleware keeps protected routes and onboarding redirects centralized.

### Core Phase 1 modules

```text
lib/
├── core/
│   ├── constants/              # Legal document versions and app constants
│   ├── bindings/               # App-level dependency composition
│   └── middleware/             # Access and onboarding route protection
├── features/
│   └── authentication/
│       ├── controllers/        # AuthController and session orchestration
│       ├── models/             # Auth user, session and consent models
│       ├── repositories/       # Auth and profile repository contracts/implementations
│       └── views/              # Login, sign-up, reset, consent and career setup
├── shared/
│   └── models/                 # Shared domain types, including career stage
└── main.dart
```

> Directory names may vary slightly as the project evolves; the responsibility boundaries above are the intended architecture.

## Getting started

### Prerequisites

- Flutter SDK (use the version pinned by the project, if provided)
- A Firebase project configured for Android, iOS and/or web
- FlutterFire configuration files for each target platform
- Google Sign-In credentials configured in Firebase and the target platforms

### Install and run

```bash
git clone <your-repository-url>
cd pro_persona
flutter pub get
flutterfire configure
flutter run
```

If Firebase is already configured in the repository, do not run `flutterfire configure` again unless you intentionally need to update the Firebase project or supported platforms.

### Firebase configuration checklist

1. Enable **Email/Password** and **Google** providers in Firebase Authentication.
2. Create a Cloud Firestore database and apply your project's security rules.
3. Register each supported application target in Firebase.
4. Add the platform configuration files generated by FlutterFire.
5. For Google Sign-In, configure Android SHA fingerprints, iOS URL schemes, and web OAuth settings as applicable.

Never commit secrets or a service-account key. Treat Firebase configuration and security rules as part of the release checklist.

### Verify the project

```bash
flutter analyze
flutter test
```
